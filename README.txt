# Haunted Mansion — Browser Version

This folder contains a standalone browser version of the Haunted Mansion text adventure.

## Play locally
Open `index.html` in a web browser.

## Share online
The easiest free option is GitHub Pages:
1. Create a GitHub account if you don't already have one.
2. Create a new repository.
3. Upload `index.html`.
4. Enable GitHub Pages for the repository.
5. GitHub will give you a public URL you can send to friends and family.

The browser version does not require Python or PyCharm.
